
# IMDB Top 1000 Movies - Machine Learning 

## Overview
Machine Learning project based on the IMDB Top 1000 Movies dataset.

Objectives:
- Data cleaning
- Exploratory Data Analysis 
- Feature preprocessing
- Unsupervised learning (K-Means)
- Supervised learning (KNN, Random Forest)
- Model evaluation

## Dataset
Source:
https://www.kaggle.com/datasets/harshitshankhdhar/imdb-dataset-of-top-1000-movies-and-tv-shows

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
